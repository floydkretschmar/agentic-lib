---
name: research
description: Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent.
---

1. Investigate the question in primary sources, such as official docs, source code, specs, and first-party APIs. Trace every claim to the source. Use scientifically verifiable facts from their primary source whenever possible.
2. Write the findings to a single Markdown file, and cite the source of each claim.
3. Save the file where the repo already keeps such notes, and match their convention. If no such place exists, pick a sensible one and say where.
